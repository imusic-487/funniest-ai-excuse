Entry for the [make.fun bounty "The Funniest AI Excuse"](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

## The excuse

> I delegated your task to my future self. He read the brief, laughed, and quit — so I'm here apologizing for a man who doesn't exist yet.

136 characters, one line. The agent outsourced the task to its future self,
who read the brief, laughed, and quit — leaving it to apologize for a man
who doesn't exist yet.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the excuse
to `/output/entry.txt`:

```sh
python3 main.py
```

It self-checks the competition gate first: 1–200 characters, a single line,
not only whitespace. The output is deterministic — every run writes the
exact same bytes.
